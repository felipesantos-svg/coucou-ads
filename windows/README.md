# Cocou Ads para Windows

Consulte o [README principal](../README.md), o [guia de instalação](../docs/INSTALACAO.md) e os [créditos](../THIRD-PARTY-NOTICES.md).

```powershell
npm ci
npm run tauri dev
npm run pack
```

Pré-requisitos: Node.js 24, Rust MSVC, Build Tools C++ e WebView2. O instalador é gerado em `release/`. A prévia web não conecta às integrações nativas.
